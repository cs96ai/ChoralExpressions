# Choral Expressions - React Application

A modern React website for Choral Expressions, a 33-member mixed-voice choral ensemble dedicated to classical mastery and soulful celebration.

## Features

- **Modern React Stack**: Built with React 18, Vite, and React Router
- **Responsive Design**: Mobile-first design using Bootstrap 5
- **Service Pages**: Dedicated pages for all services (Weddings, Christmas, Easter, etc.)
- **Booking Form**: Integrated contact form with email functionality
- **Beautiful UI**: Majestic burgundy and gold color scheme with smooth animations

## Tech Stack

- **React 18** - UI framework
- **Vite** - Build tool and dev server
- **React Router DOM** - Client-side routing
- **Bootstrap 5** - CSS framework
- **Bootstrap Icons** - Icon library
- **EmailJS** - Email service integration
